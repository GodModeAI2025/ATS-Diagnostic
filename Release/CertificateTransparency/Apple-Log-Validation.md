Apple CT directory foundation

The complete Apple directory is bundled separately from the Google directory. Every log ID is unique and matches the SHA-256 hash of its decoded public key; all state transition timestamps parse. Rejected, retired, readonly and pending entries are retained alongside qualified and usable logs. Both RFC6962 and static-ct-api entries are retained.

This is directory integrity validation, not SCT signature validation, inclusion proof validation, or a full Apple CT policy verdict. App UI integration remains pending; uploaded Build 44 does not contain this new resource.
