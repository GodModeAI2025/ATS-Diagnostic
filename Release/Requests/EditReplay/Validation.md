# Edit a request copy before replay

Record detail now opens a separate request draft with the original URL/method, deterministically ordered headers and existing request body. The draft owns its field state and does not overwrite the recorded exchange. Opening or closing the editor does not send; the existing explicit send action creates a new inspected exchange. Incomplete/unreplayable imports retain their existing restriction and cannot silently submit an unavailable body.

All136 existing app methods passed on the isolated iPad simulator. Native UI/actual-send verification is pending. This development change is not in TestFlight52 or submitted Store50. Proxy rewrite rules, maps and breakpoints remain separate open requirements.
